# Job Application Tracker

The project helps users keep track of their job applications. 

## Features

- User registration and login
- Track job applications
- Manage companies
- Add notes
- update application status

## Tech Stack

- Backend: FastAPI
- Database: POstgreSQL
- ORM: SQLAlchemy
- Migrations: Alembic
- Testing: Pytest
- DevOps: Docker, Github Actions
